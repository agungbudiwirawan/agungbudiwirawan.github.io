# agungbudiwirawan.github.io

Personal portfolio of **Agung Budi Wirawan**, Data Analyst.

Live site: https://agungbudiwirawan.github.io/

## Structure

- `index.html`: home page (about, experience, projects, skills, education, contact)
- `projects/`: one case-study page per featured project
- `assets/css`, `assets/js`, `assets/img`: styles, scripts, images and icon sprite
- `assets/pdf/`: downloadable case-study decks and CV

Plain HTML, CSS and JavaScript. No build step; GitHub Pages serves the `main` branch root.
