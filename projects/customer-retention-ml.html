The first models looked good, but weren't

  • Overfitting: an unconstrained Random Forest scored 100% on train vs 88.1% on test.
  • Class imbalance: 88.2% of orders come from returning customers. Logistic Regression scored exactly 88.2%, so it was predicting "returning" for everyone.
  • Data leakage: YearMonth took ~24% of feature importance through its cumulative time trend, so temporal features were dropped.

Honest read: separation power is moderate (ROC-AUC ≈ 0.71). A naive "everyone returns" guess scores 88% accuracy, so accuracy alone is not the metric to optimise here.

Retention playbook

  • VIP protection for Champions & Big Spenders (19.6%): early-access loyalty perks and priority support.
  • Win-back automation for At-Risk customers (19.3%), prioritised by model score.
  • Onboarding for Recent / New customers (7.4%) to secure the second purchase.

Next iteration

  • Split train/test by customer (GroupKFold) so the same customer never appears in both sets.
  • Model at customer level with RFM features; report PR-AUC and tune the decision threshold.
